✦ System Architecture

Constrained by design. Built on a Chromebook. No compute. $0 API cost. GitHub Pages static hosting. localStorage for session state. Astronomy Engine for real celestial positions. SunCalc for dawn/dusk. Browser TTS for voice. NightCafe for card images.

Every limitation forced a better choice. No backend → localStorage became session memory. API fails → the error message became atmospheric. Imperfect AI images → the reject pile became the Cave Painting archive. Static hosting only → everything runs in the browser, no server dependency.

Three layers. Digital Divination and Ealdforn are the public-facing brands — the temples people visit. Gaia is the substrate underneath — the primordial earth goddess who holds everything that doesn't have a category yet. Things gestate in Gaia. When they earn a name, they ascend to one of the brands.
